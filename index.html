Migration Overview

This guide helps you migrate ROS 1 packages to ROS 2. There are two approaches:

1 Source Code Migration: Keep most of the source code similar, maintaining parallel branches (e.g., pluginlib)
2 Functional Reimplementation: Rewrite the code with similar functionality but different implementation (e.g., roscpp → rclcpp)

Prerequisites

Before migrating, ensure all your package's dependencies are available in ROS 2.

Package Configuration Changes

Package Manifest (package.xml)

ROS 1

<package>
  <name>talker</name>
  <version>0.0.0</version>
  <description>talker</description>
  <maintainer email="user@example.com">Your Name</maintainer>
  <license>Apache 2.0</license>
  <buildtool_depend>catkin</buildtool_depend>
  <build_depend>roscpp</build_depend>
  <build_depend>std_msgs</build_depend>
  <run_depend>roscpp</run_depend>
  <run_depend>std_msgs</run_depend>
</package>

ROS 2

<package format="2">
  <name>talker</name>
  <version>0.0.0</version>
  <description>talker</description>
  <maintainer email="user@example.com">Your Name</maintainer>
  <license>Apache License 2.0</license>
  <buildtool_depend>ament_cmake</buildtool_depend>
  <depend>rclcpp</depend>
  <depend>std_msgs</depend>
  <export>
    <build_type>ament_cmake</build_type>
  </export>
</package>

Key Changes:

  • Add format="2" to package tag
  • Change catkin to ament_cmake
  • Replace roscpp with rclcpp
  • Use depend instead of separate build/run dependencies
  • Add export/build_type section

Metapackages

ROS 2 doesn't have a special metapackage type. Simply remove the <metapackage /> tag.

Build System Changes

CMakeLists.txt

ROS 1

cmake_minimum_required(VERSION 2.8.3)
project(talker)
find_package(catkin REQUIRED COMPONENTS roscpp std_msgs)
catkin_package()
include_directories(${catkin_INCLUDE_DIRS})
add_executable(talker talker.cpp)
target_link_libraries(talker ${catkin_LIBRARIES})
install(TARGETS talker
  RUNTIME DESTINATION ${CATKIN_PACKAGE_BIN_DESTINATION})

ROS 2

cmake_minimum_required(VERSION 3.5)
project(talker)

# Enable C++14
set(CMAKE_CXX_STANDARD 14)

find_package(ament_cmake REQUIRED)
find_package(rclcpp REQUIRED)
find_package(std_msgs REQUIRED)

include_directories(include)
add_executable(talker talker.cpp)
ament_target_dependencies(talker
  rclcpp
  std_msgs)

install(TARGETS talker
  DESTINATION lib/${PROJECT_NAME})

ament_package()

Key Changes:

  • Require CMake 3.5+
  • Set C++14 standard
  • Use ament_cmake instead of catkin
  • Find each package separately
  • Use ament_target_dependencies for linking
  • Install to lib/${PROJECT_NAME}
  • Call ament_package() at the end

Build Tools

Replace catkin_make with colcon build:

# ROS 1
catkin_make install

# ROS 2
colcon build

Source Code Migration

Includes

ROS 1

#include "ros/ros.h"
#include "std_msgs/String.h"

ROS 2

#include "rclcpp/rclcpp.hpp"
#include "std_msgs/msg/string.hpp"

Node Initialization

ROS 1

ros::init(argc, argv, "talker");
ros::NodeHandle n;

ROS 2

rclcpp::init(argc, argv);
auto node = rclcpp::Node::make_shared("talker");

Publisher Creation

ROS 1

ros::Publisher chatter_pub = 
  n.advertise<std_msgs::String>("chatter", 1000);

ROS 2

auto chatter_pub = node->create_publisher<std_msgs::msg::String>(
  "chatter", 1000);

Message Definition

ROS 1

std_msgs::String msg;

ROS 2

std_msgs::msg::String msg;

Logging

ROS 1

ROS_INFO("%s", msg.data.c_str());

ROS 2

RCLCPP_INFO(node->get_logger(), "%s", msg.data.c_str());

Main Loop

ROS 1

while (ros::ok()) {
  ros::spinOnce();
}

ROS 2

while (rclcpp::ok()) {
  rclcpp::spin_some(node);
}

Parameters

In ROS 2, parameters are associated per node rather than with a central server.

Quick Reference

Feature ROS 1 ROS 2
Remapping foo:=bar -r foo:=bar
Parameters _foo:=bar -p foo:=bar
Node name __name:=foo -r __node:=foo
Namespace __ns:=foo -r __ns:=foo

Important Notes:

  • ROS 2 arguments should be scoped with --ros-args
  • No ROS 2 equivalent for __log, __ip, __hostname, __master

Launch Files

ROS 2 supports Python scripts for launch files (recommended) as well as XML and YAML.

ROS 1 XML

<launch>
  <node pkg="talker" 
        type="talker" 
        name="talker" 
        output="screen"/>
</launch>

ROS 2 Python

from launch import LaunchDescription
from launch_ros.actions import Node

def generate_launch_description():
    return LaunchDescription([
        Node(
            package='talker',
            executable='talker',
            name='talker',
            output='screen'
        )
    ])

Migration Tools:

Consider using the ROS 2 Launch File Migrator to convert XML launch files to Python.

Complete Example: ROS 1 to ROS 2 Talker

ROS 1 Talker

#include <sstream>
#include "ros/ros.h"
#include "std_msgs/String.h"

int main(int argc, char **argv) {
  ros::init(argc, argv, "talker");
  ros::NodeHandle n;
  ros::Publisher chatter_pub = 
    n.advertise<std_msgs::String>("chatter", 1000);
  ros::Rate loop_rate(10);
  
  int count = 0;
  std_msgs::String msg;
  
  while (ros::ok()) {
    std::stringstream ss;
    ss << "hello world " << count++;
    msg.data = ss.str();
    ROS_INFO("%s", msg.data.c_str());
    chatter_pub.publish(msg);
    ros::spinOnce();
    loop_rate.sleep();
  }
  return 0;
}

ROS 2 Talker

#include <sstream>
#include "rclcpp/rclcpp.hpp"
#include "std_msgs/msg/string.hpp"

int main(int argc, char **argv) {
  rclcpp::init(argc, argv);
  auto node = rclcpp::Node::make_shared("talker");
  auto chatter_pub = node->create_publisher<std_msgs::msg::String>(
    "chatter", 1000);
  rclcpp::Rate loop_rate(10);
  
  int count = 0;
  std_msgs::msg::String msg;
  
  while (rclcpp::ok()) {
    std::stringstream ss;
    ss << "hello world " << count++;
    msg.data = ss.str();
    RCLCPP_INFO(node->get_logger(), "%s", msg.data.c_str());
    chatter_pub->publish(msg);
    rclcpp::spin_some(node);
    loop_rate.sleep();
  }
  return 0;
}
